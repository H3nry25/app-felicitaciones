# Felicitaciones de Graduación 🎓✨

Una tarjeta digital de felicitación de graduación interactiva, elegante y con detalles artesanales.

## ✨ Características

- 💌 **Diseño estilo carta y papelería fina**: Textura de papel marfil con cinta washi y tipografía editorial.
- 🏊‍♀️ **Recuerdos interactivos en Polaroids**: Mención especial a pasiones y logros (aguas abiertas, podios y esculturas de chocolate).
- 🎉 **Celebración interactiva**: Botón de confeti con física realista y animaciones suaves.
- 📱 **Completamente adaptable (Responsive)**: Diseñado para verse perfecto tanto en computadoras como en teléfonos móviles.

## 🚀 Cómo ver el proyecto

Simplemente abre el archivo `index.html` en cualquier navegador web moderno, o publícalo en GitHub Pages para compartir el enlace.
